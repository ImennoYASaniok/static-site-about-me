## 🎯 Проблема и Цель

### Проблема
Нужен персональный сайт, который:
- Содержит несколько независимых страниц (главная, обо мне, проекты, контакты, игры)
- Имеет единый визуальный стиль и общие UI-компоненты
- Легко собирается и деплоится как статический сайт
- Поддерживает встроенные мини-игры без дополнительного backend

### Цель
Сделать удобный и расширяемый многостраничный сайт с:
- Современным фронтенд-стеком на Vite
- Централизованной системой стилей на Sass
- Отдельными страницами игр (`Snake`, `Dino`, `Life`, `Minesweeper`)
- Быстрым локальным запуском и production-сборкой

## ✨ Основные Возможности

- Многостраничная структура (`index`, `about`, `projects`, `contacts`, `games`)
- Отдельные игровые страницы в `games/`
- Единая точка входа `src/main.js` для интерактивности
- Стилизация через модульные SCSS-файлы (`base`, `layout`, `components`, `pages`)
- Поддержка локальных шрифтов через `public/fonts`
- Эксперименты и старые standalone-страницы хранятся отдельно в `reference/`

## 📦 Требования

- **Node.js**: 18+ (рекомендуется LTS)
- **npm**: 9+

## 🚀 Как Запустить Проект

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

После запуска открой адрес из терминала (обычно `http://localhost:5173`).

### 3. Production-сборка

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

### 4. Локальный просмотр production-сборки

```bash
npm run preview
```

## 🏗️ Архитектура

Проект построен как MPA (multi-page application) на Vite:

- Корневые HTML-страницы выступают entry points
- Дополнительные игровые страницы находятся в `games/`
- Vite собирает все точки входа в `dist/` (конфиг в `vite.config.js`)
- JS-логика и стили находятся в `src/`

## 📂 Структура Проекта

```text
static-site-about-me/
├── games/                  # Рабочие страницы игр
├── public/                 # Исходные статические файлы: fonts и images
├── reference/              # Референсы, эксперименты и legacy-код
│   ├── experiments/        # Изолированные визуальные эксперименты
│   └── legacy/             # Старые страницы, не входящие в приложение
├── src/
│   ├── main.js             # Общая клиентская логика
│   └── styles/             # SCSS: base/layout/components/pages
├── about.html
├── contacts.html
├── games.html
├── index.html
├── projects.html
├── package.json
└── vite.config.js
```

`dist/` не хранится в рабочем дереве: это временный результат `npm run build` и он пересоздается автоматически.

## 🛠️ Скрипты

- `npm run dev` — запуск локального dev-сервера Vite
- `npm run build` — production-сборка в `dist/`
- `npm run preview` — локальный просмотр production-сборки
